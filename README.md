# Voice Assistant 🎙️

This is a simple **Voice Assistant** built using Python that can recognize voice commands and respond accordingly.

## 🚀 Features
- Converts speech to text  
- Responds to user inputs  
- Uses `pyttsx3` for text-to-speech conversion  
- Uses `speech_recognition` for voice commands  

## 🛠️ Technologies Used
- Python  
- pyttsx3 (Text-to-Speech)  
- speech_recognition (Speech-to-Text)
